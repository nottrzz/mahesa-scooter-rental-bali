# Mahesa Scooter Rental Bali

Static website for Mahesa Scooter Rental in Bali.

## Files

- `mahesa.html` - main website page
- `scooter-rental-bali.html` - rental bike landing page
- `.htaccess` - Apache directory index, HTTPS redirect, compression, and cache settings

Deploy these files to the site's Apache document root. The `.htaccess` rules require Apache with `mod_rewrite`; compression and cache rules are enabled when their modules are available.
